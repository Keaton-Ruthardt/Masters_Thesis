Wiring 4 pressure sensors into the ball

How the sensors share one power pin, how each female connector joins the board, and where each sensor sits under the leather. Everything here is buildable now except dropping in the four 10 kΩ resistors.

The part that confused you: one 3.3V pin feeds all four

3.3V is a shared rail — not one pin per sensor. You run one wire from the XIAO's single 3V3 pin to a common junction, then branch that junction to all four sensors. Ground works the same way in reverse: all four resistors meet at one junction that returns to the single GND pin. Your breadboard has been doing this the whole time — the red power rail is that shared junction. You'll just rebuild it as a solder splice (or a tiny scrap of perfboard) inside the ball.

Only the A0–A3 connections are unique — each sensor gets its own analog pin. Power and ground are shared buses. Each sensor draws only microamps, so one pin driving four is completely normal.

Full wiring — the ladder

Read it as four identical rungs between two shared rails: 3.3V on top, GND on the bottom. Each rung is one voltage divider: 3.3V → sensor → node → 10 kΩ → GND, with the node tapped off to its own ADC pin.

One sensor, end to end

The A201's tab is two male pins on 0.1 in spacing. A female connector clips straight on — no heat on the sensor. From the connector, two wires run back to the board: one joins the shared 3.3V rail, the other is the ADC node (where the 10 kΩ to GND also lands).

Where each sensor sits — four-seam grip

Map the pads to a four-seam grip so they sit exactly where the fingers press. Index and middle on top near the seams, thumb underneath, ring on the side. Label each pad to its sensor and pin as you place it.

Pin map: S1 index → A0  ·  S2 middle → A1  ·  S3 thumb → A2  ·  S4 ring → A3  — matches PIN[4] = {A0,A1,A2,A3} in the firmware.

Build order

Everything below is doable now except step 5 (needs the 10 kΩ). Pre-build 1–4 while you wait.

  1. Build 4 sensor harnesses. Female connector onto each A201's pins, lock with heat-shrink/glue, run two wires (consistent colors: red = power side, teal = ADC side). Label S1–S4.
  2. Make the 3.3V junction. Splice all four red wires together with one wire back to the XIAO 3V3 pin — this is your shared rail.
  3. Make the GND junction. One wire from the XIAO GND pin to a common node all four resistors will return to.
  4. Route each ADC wire from each sensor to its own pin — S1→A0, S2→A1, S3→A2, S4→A3.
  5. Add the four 10 kΩ resistors. Each one from its ADC node to the GND junction. (Waiting on parts.)
  6. Bench-test before the ball. Run the logger, press each pad, confirm the correct channel moves. Only then embed and seal.
