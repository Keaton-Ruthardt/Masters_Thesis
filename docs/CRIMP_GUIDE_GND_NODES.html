GND bus & the node pins

You built the 3V3 bus. Now the ground return, and the four "node" connectors that plug onto A0, A2, A4, A5. Same crimp skill — just different things going into the barrel.

3V3 (done) GND node / signal resistor leg sensor
◎

What one channel looks like

Each of the 4 channels is this. The node is where the sensor signal, the resistor's top leg, and the wire to the analog pin all meet — that's one crimp. The resistor's bottom leg goes to the GND bus.

1

GND bus: gather the 4 resistor legs

The four resistors' bottom legs all go to ground. Bend them together to one spot. Four stiff legs are too fat for a plain barrel — so use a ferrule.

2

Crimp the ferrule, then onto GND

Insert all four legs (plus a short wire to the XIAO's GND pin) into the ferrule and crimp. That single ferrule end goes into a female contact → the GND pin. Heat-shrink it.

3

Make a node: two things into one contact

For each channel, put the sensor's signal wire and the resistor's top leg into one female contact. That contact plugs onto the analog pin — so the node is sealed inside the housing, not floating in the open.

4

Repeat for all four — onto A0, A2, A4, A5

Skip A1 and A3. Using every-other pin keeps the four nodes physically apart so they can't bridge — the exact fix for what broke the first ball.

5

Then the gate: isolation test

Power the XIAO, flash isolation_test. Press one pad — only its channel should move; the others stay under 5%. If a second channel follows, two nodes are bridged: fix before you go further.

!

Same rules as the 3V3 crimps: tug-test and beep every joint. Wash with 99% IPA, heat-shrink each barrel, then conformal-coat once the isolation test passes.

That completes the harness: 3V3 bus + GND bus + 4 nodes on A0/A2/A4/A5. Next in the build manual: place sensors under the cover, coat, pot at center, ballast, re-lace.
